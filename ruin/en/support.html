Support

RUIN is still in development and there is no public build yet. This page is written ahead of release so that it can be used as it is, and it will be corrected whenever the build changes.

How to get help

  1. Check Controls and Known limitations below first.
  2. If that does not solve it, write to the address under Contact. One developer reads and answers every message. A reply usually takes a few days and can take longer.
  3. It helps to include: your Mac model and macOS version, where you got the game, what you were doing and what happened. Please send record files only if asked.

Controls

Keyboard and mouse

Hold XSkip a scene. A short press does nothing.

Gamepads are supported. The left stick walks and the right stick looks. The bottom face button (A or ✕) interacts and confirms, the right one (B or ○) declines and cancels, the left one (X or □) switches the view, holding the top one (Y or △) skips a scene, and Start (Options) opens the menu. On-screen prompts follow the device you used last.

This describes the build in development. If the release build differs, this table will be corrected.

Where your records are kept

Records exist only on your Mac. The game sends them nowhere.

~/Library/Application Support/RUIN/ShortEpisode/v1/slot-01/

In Finder, press ⇧ ⌘ G (Go → Go to Folder) and paste the path. The Mac App Store version keeps the same structure inside the app's own folder.

~/Library/Containers/(app identifier)/Data/Library/Application Support/RUIN/

A store version and a directly downloaded version cannot see each other's records. That is how macOS protects apps; nothing is broken.

"New game" never deletes an old record

When you choose New game (새 게임) in the menu, the current record is not deleted. It is moved into an archive folder, and each move creates a new dated folder there.

~/Library/Application Support/RUIN/ShortEpisode/v1/slot-01/Archive/

The game has no function that deletes a record. If you want to go back to an archived record, write in and you will be told how.

Removing everything

Deleting the app leaves your records in place. To remove records and options as well, quit the game and move the folder ~/Library/Application Support/RUIN to the Bin yourself.

Resetting options

  1. Quit the game.
  2. Delete this file, or move it somewhere else. 
    ~/Library/Application Support/RUIN/options-v1.cfg
  3. Start the game again. It starts with default options and writes a new file.

Deleting the options file does not touch your progress. If the options file is damaged and cannot be read, the game does not delete it: it renames it to options-v1.damaged.cfg and starts with defaults.

Known limitations

  • In development. No release date or price has been set, and there is no build to download yet.
  • Apple Silicon Macs only. It does not run on Intel Macs.
  • Windows and iPhone/iPad are under consideration and are not promised.
  • Minimum requirements and the supported macOS version have not been measured yet. They will be listed once they have been.
  • There is one record slot.
  • The whole game is about 10 minutes long. That is all of it.
  • Languages: Korean and English.
